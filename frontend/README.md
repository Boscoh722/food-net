# Food-Net Frontend

## Setup
1. `cd frontend`
2. `npm install`
3. `npm run dev`

## Features
- Interactive Kenya map with product pins
- Search by location or item
- Role-based dashboards
- Order tracking
- Complaints system
- Tailwind CSS v4 + Dark Mode

## Tech
- React 18 + Vite
- Tailwind CSS v4 (JIT)
- Leaflet Map
- Axios + JWT Auth
